# Campus Life documentation

Campus Life is a multiplayer campus (modelled on a college campus in Bomi, Liberia) built around one feeling:
*"I am on campus with these people, and something is always happening."*

| Document | What it covers |
|---|---|
| [vision.md](vision.md) | The design principles every feature is tested against |
| [architecture.md](architecture.md) | How the pieces fit: client, game server, shared package, database |
| [campus-map.md](campus-map.md) | The physical campus, both floors, zones and seats |
| [protocol.md](protocol.md) | Every WebSocket message, who sends it, and the rules behind it |
| [3d-plan.md](3d-plan.md) | Full 3D plan, phases A to I, Student Center and DJ plan |
| [day-cycle.md](day-cycle.md) | The campus day: classes, free time, dusk, party, bedtime, dawn, specials and social rewards |
| [economy.md](economy.md) | Every way to earn and spend LD |
| [3d-renderer.md](3d-renderer.md) | The 3D renderer, how to run and tune it |
| [testing.md](testing.md) | How to run it, how to test with friends, what to look for |
| [roadmap.md](roadmap.md) | Phases 1 to 10 and the 3D phases A to J |
| [jobs-and-lectures.md](jobs-and-lectures.md) | The Jobs Board and the Lecture Area |

| [phase-3-talk.md](phase-3-talk.md) | Nearby chat, bubbles, whisper, quick phrases, reactions |

Start with `testing.md` if you want to run the game, and `architecture.md` if you want to change it.
